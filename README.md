## String Manipulation in JavaScript 🧵

A lightweight JavaScript demonstration showcasing essential string manipulation methods such as .replace(), .replaceAll(), .repeat(), and template literals.

## 📌 Features

String Replacement: Demonstrates basic .replace() for single occurrences and .replaceAll() for global replacement.

String Repetition & Trimming: Shows how to dynamically repeat strings with .repeat() and clean up whitespace using .trimEnd().

Template Literals: Modern string interpolation using standard ES6 syntax.

## 🚀 🛠️ Usage

You can run this project locally using Node.js or inside your browser's developer console.

## Running with Node.js

Ensure you have Node.js installed.

## Clone this repository:

git clone https://github.com/willpaes/string-manipulation-js.git


## Navigate to the project directory:

cd string-manipulation-js


## Execute the script:

node index.js


## 📋 Output

Original string:
I love cats.
After using the replace() method:
I love dogs.

Original sentence:
I love cats and cats are so much fun!
Replacing all occurrences of cats with dogs:
I love dogs and dogs are so much fun!

Original learning sentence:
I love learning!
love love love
I love love love learning.
